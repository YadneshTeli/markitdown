# MarkItDown TypeScript Examples

Ready-to-run examples demonstrating MarkItDown in JavaScript & TypeScript.

## 🚀 Running Examples

Run directly using `npx tsx`:

```bash
# 1. Basic conversion (Text, CSV, HTML, documents)
npx tsx examples/typescript/basic-conversion.ts

# 2. Plugins & OCR (Tesseract.js WebAssembly & dynamic discovery)
npx tsx examples/typescript/plugin-and-ocr.ts
```

## 📂 Included Examples

- [`basic-conversion.ts`](basic-conversion.ts): In-memory buffer conversion, table parsing, HTML-to-Markdown conversion.
- [`plugin-and-ocr.ts`](plugin-and-ocr.ts): Plugin listing, automatic plugin activation, local Tesseract OCR converter registration.
